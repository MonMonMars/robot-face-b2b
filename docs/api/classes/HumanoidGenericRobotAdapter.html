    Class HumanoidGenericRobotAdapter

    Extension point for Tesla Optimus–class and similar humanoid face/display stacks.

    Bridge mode (humanoidBridge=1 / HUMANOID_BRIDGE=1): sends robot-face.humanoid-expression.v1 JSON to humanoidBridgeUrl.
